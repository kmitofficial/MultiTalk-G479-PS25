# 🎬 MultiTalk: Multi-Person Audio-Driven Conversational Video Generator

## 🧠 Project Overview

Current audio-driven animation models struggle to generate realistic **multi-person conversational videos**, often due to:
- Incorrect **audio-person associations**
- Poor **instruction-following capabilities**

**MultiTalk** is a system designed to overcome these limitations by:
- Accurately binding multiple audio streams to the corresponding animated characters
- Enhancing synchronization and dialogue coherence using advanced techniques like **Label Rotary Position Embedding (L-RoPE)** and **multi-task learning**

---

## 🚀 Development Goals

The key tasks for this project include:

✅ **1. System Architecture**  
Design the overall architecture to handle multi-person audio-driven video generation with instruction-following.

✅ **2. Audio-Person Binding with L-RoPE**  
Implement **Label Rotary Position Embedding** to bind each audio stream to the correct character.

✅ **3. Multi-Stream Audio Synchronization**  
Develop a module to inject and synchronize multiple audio streams for realistic dialogue flow.

✅ **4. Instruction Parser Integration**  
Build an instruction parser to guide each character’s dialogue and visual gestures.

✅ **5. Video Rendering Pipeline**  
Create a high-quality rendering system for generating final conversational videos.

✅ **6. Performance Evaluation**  
Test on benchmark datasets and analyze results based on synchronization, realism, and instruction-following accuracy.

## 🙋‍♀️ Who Can Use MultiTalk?

MultiTalk is designed for a variety of users:

- 🎬 **Content Creators**: Generate engaging multi-character animated videos from audio instructions.
- 🧪 **Researchers**: Experiment with multi-modal learning using L-RoPE and instruction parsing.
- 👨‍💻 **Developers**: Integrate MultiTalk modules into conversational AI or avatar systems.
- 🎓 **Students & Educators**: Use it as a learning resource for audio-driven animation and video synthesis.
